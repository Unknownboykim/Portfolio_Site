Ecommerce AI Analyst

An analytics app where users pick a business question from a menu or search by keywords, and get a results table, a chart, and an optional OpenAI write-up of the findings. I built the full ETL pipeline from a public API into SQLite, wrote 18 reviewed SQL queries that catch planted problems like discount abuse, dead stock, and duplicate SKUs, and kept the LLM grounded by having it explain only the rows each query returns.
